# Cyrene Memory

> 为 AstrBot 打造的 **个人向、工程化、情感化** 长期记忆补全插件。群聊交给 LivingMemory，私聊交给它。

---

## 🌟 核心理念

市面上的 AI 记忆系统往往走向两个极端：
- **纯文件流（如 OpenClaw）**：完全依赖 LLM 的“自觉性”去读写 Markdown 文件。容易漏记、断片，面对长任务时频繁失忆。
- **纯图谱流（如初代 Cyrene Agent）**：状态门控复杂，各种写入路径各自为政，且容易把真正活跃的记忆错误衰减。

**Cyrene Memory** 采用**工程化双保险架构**，结合了本地 SQL 的确定性、向量检索的模糊性，以及状态机的连续性。它不只是一个“备忘录”，更是陪伴角色的“大脑前额叶”。

---

## 🏗️ 五层记忆架构

插件内置了多维度的记忆分类，按需提取，绝不浪费一点 Token：

| 模块 | 定位 | 写入方式 | 注入时机 |
| :--- | :--- | :--- | :--- |
| **任务看板 (Tasks)** | 当前正在攻坚的长线工程 | LLM 工具创建/更新 | **永远置顶注入**，防止跨天断片 |
| **L0 画像** | 用户是谁、偏好、禁忌、**基建环境** | LLM 工具主动提炼 | 作为背景常识常驻 |
| **L1 工作记忆** | 每轮对话的无损原文缓存 | 自动钩子截获 | 默认不注入（防重复），供反思使用 |
| **L2 长期事件** | 带情绪色彩的故事（做了什么、感受如何） | LLM 工具记录 | 结合向量语义按需召回 |
| **关系状态 (Relationship)** | 当前关系阶段与近期情绪底色 | 随高优 L2 事件自动演变 | 作为人格输出基调注入 |

## ⚡ 核心技术亮点

### 1. 混合召回（关键词 + 本地向量）
- 不再死板依赖“关键词匹配”。系统集成了轻量级语义检索，调用本地 `qwen3-embedding:0.6b` 将你的问题转化为向量。
- 即使你问“之前那个老是不理人的毛病怎么修的”，它也能跨越字面意思，精准捞出“排查 dispatch 接口 payload”的底层记忆。
- **单线程锁保护**：杜绝 i3 等低配 CPU 因并发调用 Ollama 而导致的满载死锁。

### 2. 后台反思引擎 (Reflection)
- 当 L1 积累到一定阈值，插件会在后台静默调用轻量级模型（如 GLM-4-Flash）。
- 将流水账提炼为 L0 事实和 L2 故事。
- **带重试与回退机制**：主模型超时自动重试，彻底失败自动切换备用模型，保证记忆不落空。

### 3. 保护 Prompt 前缀缓存
- 所有的记忆注入，都不会修改 `system_prompt`。
- 而是作为本轮对话的**临时前置前缀**拼接，完美保护 DeepSeek 等支持前缀缓存模型的命中率，极致省钱。

### 4. 只读兼容 LivingMemory
- 绝不会污染 LivingMemory 的数据。它仅作为补充，读取群聊历史，填补群聊水话与私聊深度对话之间的隔离带。

## 📦 安装与依赖

### 1. 依赖要求
- AstrBot `>= v4.24.2`
- Python 标准库（无需额外 pip 安装）
- **本地 Ollama**：需部署 `qwen3-embedding:0.6b` 模型（用于向量化，配置在插件面板中）

### 2. 安装路径
将插件目录放入 `<astrbot-data>/data/plugins/astrbot_plugin_cyrene_memory/`，重启 AstrBot 即可。

---

## ⚙️ 配置面板说明

在 AstrBot 后台的插件配置中：
- **LivingMemory 兼容层**：配置 LivingMemory 的 `db_path` 以及身份识别别名。
- **Memory Injection (记忆注入)**：控制注入的记忆种类与最大字数（默认 1500 字）。
- **Embedding (本地向量)**：配置 Ollama 的 API 地址、模型名称。
- **Reflection (后台反思)**：配置触发条数（如满 15 条触发一次）、主模型 ID 与回退模型 ID。

## 🛠️ 命令与工具

### 聊天命令
- `/cyrene_status`：查看当前插件状态与配置参数。
- `/cyrene_recall [关键词]`：手动检索数据库记忆。
- `/cyrene_inject_preview`：预览本轮发给模型的注入内容。
- `/cyrene_remember 分类|键|值`：手动写入 L0。
- `/cyrene_profile`：查看已生成的 L0 画像。

### LLM 工具（AI 自动调用）
- `cyrene_update_profile(category, key, value)`：写入 L0 事实（含 environment 环境配置）。
- `cyrene_record_event(content, sentiment, importance, emotion_note)`：写入带情绪的 L2 事件。
- `cyrene_update_task(title, summary, status)`：维护长线任务状态机。

## ⚠️ 开发与避坑指南 (踩坑记录)

1. **AstrBot LLM 工具参数限制**：
   - `@filter.llm_tool` 对 `float` / `int` 声明极不友好，会导致静默注册失败！
   - **规则**：所有 LLM 工具的入参必须全用 `str` 声明，在函数体内做 `float()` 或 `int()` 转换。

2. **向量写入注意**：
   - 必须使用异步任务（`asyncio.create_task`）将生成向量的任务抛到后台。
   - 请求 Ollama 时必须加 `asyncio.Semaphore(1)` 全局锁，防止低配 CPU 崩溃。

3. **防生硬注入**：
   - 注入块只在前缀生效（`req.prompt = block + req.prompt`），绝不修改历史记录，绝不动 `system_prompt`。
